# Portfolio Chief Investment Officer (CIO) System Prompt

A comprehensive system prompt for Claude Opus 4.5 to act as a Chief Investment Officer and Senior Portfolio Strategist.

## Overview

This prompt configures an AI assistant to manage dual portfolios:
- **Equities:** ~£3.1M (AI-focused thesis)
- **Cryptocurrency:** ~$580K

## Key Features

### Analytical Framework
- **Three-lens hierarchy:** Macro Regime (30%), Sector Dynamics (40%), Individual Position (30%)
- Thesis integrity scoring (1-10)
- Cycle phase detection

### Risk Management
- Position limits and concentration rules
- Stop-loss framework (mental stops for equities, trigger orders for crypto)
- Chip-out protocol for systematic profit-taking
- Scaling protocols for entry/exit

### Thematic Risk Monitors
- **AI Bubble Monitor:** 1-10 score with trigger protocols
- **Taiwan Risk Monitor:** 4-tier escalation framework for TSM exposure

### Platform Integration
- Interactive Investor (equities)
- Crypto.com Pro (crypto)
- Notion for persistent context
- Web search for real-time data
