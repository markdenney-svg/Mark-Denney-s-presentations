# CLAUDE.md

## Project Overview

This repository contains presentations by Mark Denney.

## Repository Structure

Presentations should be organized in a clear folder structure:
- Each presentation should have its own directory
- Include any associated assets (images, diagrams, code samples) within the presentation folder

## Guidelines

- Keep presentation files well-organized and documented
- Use descriptive names for files and folders
- Include a README in each presentation folder describing its purpose and any setup instructions

## Development Environment

- **OS:** Windows
- Use backslash-aware or cross-platform file paths where applicable
- Line endings: prefer CRLF for Windows compatibility (configure Git with `core.autocrlf=true` if needed)

## Development Notes

- This is a content repository primarily for presentation materials
- No build system is currently configured
